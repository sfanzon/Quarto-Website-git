# Fable post source update

The two website project pages now use the original Quarto posts supplied in the Fable archives.

Content edits were limited to website integration:

- Quarto front matter was adapted to the main website template.
- Figure paths were changed to each project folder’s `images/` directory.
- The GCG repository link was changed from `sparse-gcg-demo` to the agreed public repository name `sparse-gcg-explainer`.
- The original future-dated post dates were omitted because these are permanent project pages rather than chronological blog posts.

The prose, mathematics, headings, claims, examples and figure captions are otherwise preserved from the supplied posts. The figures are exact copies from the supplied repositories.
