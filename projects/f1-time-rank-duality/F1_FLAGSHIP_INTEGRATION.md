# F1 flagship integration

The main website owns three internal pages:

- `index.qmd` — industry-facing overview;
- `technical.qmd` — a snapshot of the repository's technical walkthrough;
- `code.qmd` — a snapshot of the repository README and deployment guide.

The repository ZIP remains downloadable from `downloads/F1-Paper-Code.zip`.
There is no build-time dependency on the external repository. To refresh the
website snapshots later, copy the relevant source files from the repository and
render the main website normally.
