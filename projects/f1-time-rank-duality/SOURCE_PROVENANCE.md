# F1 website snapshot provenance

The website pages use presentation-adapted snapshots of the latest uploaded
`F1-Paper-Code` repository. The scientific wording and code examples come from
the repository, but the website view is not byte-for-byte identical: its top
resource links, internal URLs, heading levels and side-navigation metadata are
adapted for the main website.

Untouched source copies are stored in `source-snapshots/`, and the complete
repository is downloadable from `downloads/F1-Paper-Code.zip`.
